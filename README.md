# Meu Hobby Favorito: Leitura 📚

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica para apresentar meu hobby favorito: a leitura.

O site reúne três plataformas que utilizo para ler, pesquisar livros e acompanhar resenhas e recomendações de outros leitores.

## Tecnologias utilizadas

- **Python:** utilizado para gerar os arquivos do site.
- **HTML:** responsável pela estrutura da página.
- **CSS:** responsável pelas cores, fontes e organização visual.

## Sites apresentados

- **Kindle:** plataforma para leitura de livros digitais.
- **Amazon:** utilizada para pesquisar e comprar livros.
- **TikTok:** utilizado para acompanhar resenhas e recomendações literárias, principalmente no BookTok.

## Como executar

1. Baixe e extraia os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo Python pelo terminal:

```bash
python criar_site.py
```

4. Abra o arquivo `index.html` no navegador.

Também é possível abrir diretamente o `index.html`, pois os arquivos da página já estão incluídos no projeto.

## Objetivo

Praticar conceitos básicos de desenvolvimento web, como utilização de títulos, imagens, links e estilização de páginas, integrando conhecimentos de Python, HTML e CSS.
